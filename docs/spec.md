# Transformer架构交互式学习单页应用开发提示词

## 项目概述

开发一个**纯前端单页应用（HTML + CSS + JavaScript）**，用于交互式学习Transformer架构及其历史演进。应用需包含完整的模型结构可视化、张量数据流追踪、历史时间轴三大核心功能。所有计算基于**TensorFlow.js**实现，在浏览器中完成前向推理模拟。

---

## 技术栈要求

| 技术 | 用途 |
|------|------|
| TensorFlow.js (CDN) | 矩阵运算、张量操作、模型加载 |
| D3.js 或 ECharts | 网络结构图绘制、注意力热力图 |
| 原生 HTML/CSS/JS | 零依赖主框架，确保单文件运行 |
| Canvas 或 SVG | 动态数据流动画 |

---

## 功能需求清单

### 1. 历史演进时间轴（左侧面板）

**数据要求：**
- 年份节点：2000（RNN/LSTM）→ 2014（Seq2Seq+Attention）→ 2017（Transformer）→ 2018（BERT）→ 2019（GPT-2）→ 2020（GPT-3）

**交互要求：**
- 点击年份节点 → 右侧架构图高亮对应模块
- 每个节点显示关键论文标题和核心贡献（如 "Attention Is All You Need"）
- 时间轴支持滚动或缩放

### 2. Transformer核心架构解剖（中央主区域）

**需实现的可视化模块：**

| 模块 | 必需展示内容 |
|------|-------------|
| 输入嵌入层 | Token → Embedding + 位置编码 过程 |
| 多头自注意力 | Q/K/V 计算、缩放点积、注意力矩阵热力图 |
| 残差连接 + LayerNorm | 可视化"Add & Norm"的跳跃连接 |
| 前馈网络 | 两层线性层 + ReLU 激活 |
| Encoder 完整结构 | 以上模块串联 + 堆叠 N 层 |
| Decoder 结构 | 带掩码的交叉注意力 |

**交互要求：**
- 鼠标悬停/点击任何子模块 → 下方显示：
  - 该模块的**数学公式**（LaTeX格式）
  - **张量形状变化流程**（如 `[batch, seq_len, d_model] → [batch, seq_len, d_model]`）
  - **核心代码片段**（使用 tfjs API）
  - **参数数量统计**

### 3. 交互式数据流演示（右侧面板）

**输入方式：**
- 文本输入框（预设示例："我 爱 自然语言处理"）
- 或下拉选择预设句子

**前向传播可视化步骤：**
1. 分词（Tokenization）
2. 嵌入（Embedding）→ 显示形状
3. 位置编码（Positional Encoding）→ 显示波形图
4. Encoder 第1层 → 显示注意力热力图
5. Encoder 第N层 → 显示输出表示
6. （可选）Decoder生成过程 → 逐词预测演示

**每步要求：**
- 当前处理模块**高亮**
- 实时更新张量**形状和数值范围**（如 min/max/mean）
- 显示处理耗时（ms）

### 4. 注意力可视化（增强功能）

- 绘制**注意力热力图**：行=Query词，列=Key词
- 支持选择**不同头**（Head 1-8）查看注意力模式
- 动态展示 Softmax 前后的分数变化

### 5. 模型参数配置面板

提供可调节的超参数：
- `d_model`（512 / 256 / 128）
- `num_heads`（8 / 4 / 2）
- `num_layers`（6 / 3 / 1）
- `dropout_rate`（0.1 / 0.0）

调整参数后，**所有张量形状和参数数量自动更新**。

### 6. 代码导出功能（可选）

- 显示当前配置对应的 TensorFlow.js 模型构建代码
- 支持一键复制

## 关键公式（需在详情面板展示）

**缩放点积注意力：**
\[
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
\]

**多头注意力：**
\[
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, ..., \text{head}_h)W^O
\]
\[
\text{head}_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)
\]

**位置编码：**
\[
PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)
\]
\[
PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{\text{model}}}}\right)
\]

**前馈网络：**
\[
\text{FFN}(x) = \max(0, xW_1 + b_1)W_2 + b_2
\]
