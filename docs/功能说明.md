# Transformer 架构演进可视化 · 功能说明

> 页面右上角「❓ 功能说明」按钮可随时打开本说明的精简版（首次访问自动弹出）。本文档是完整版。English version: [docs/guide-en.md](./guide-en.md)。

## 一、这个项目是什么

一个**纯前端单文件**交互式演示：在浏览器里走完 1943（MP 神经元）→ 2026（推理效率竞赛）的深度学习/大模型架构进化之路。核心卖点是**所有前向计算都是真实的 TensorFlow.js 运算**，不是动画模拟——你看到的注意力热力图、生成文本、微调 loss 曲线都来自真实张量计算。

技术栈：原生 HTML/CSS/JS · TensorFlow.js 4.x（推理）· D3.js 7（图表）· KaTeX（公式）。

## 二、三栏布局怎么用

| 栏 | 名称 | 用法 |
|----|------|------|
| 左 | 时间轴 | 55+ 里程碑论文按四阶段分组。点节点 → 中间架构图高亮对应模块 + 弹出解释抽屉 |
| 中 | 架构图 + 图表 | 上：当前视图的结构图，点任意模块出解释；下：注意力热力图（层/头/Softmax 前后可切）、Model View、Neuron View |
| 右 | 运行台 | 输入文本 → 分词 → 超参数 → ▶ 运行真实前向传播；底部控制台支持播放/暂停/单步/回退 |

## 三、顶部视图按钮的关系（重要）

那排按钮不是并列功能，而是**演进时间线上的分流**：

```
前传·基石 (1943-2016)
  └─ 前史 RNN→2017
       └─ 2017 原版 Encoder-Decoder
            ├─ Decoder-Only·Dense   ← GPT / LLaMA / Qwen 这条主流线
            ├─ Decoder-Only·MoE     ← Switch / Mixtral / DeepSeek-V3 稀疏化分流
            ├─ Attention 演进        ← MHA→MQA→GQA→MLA、FlashAttention、NSA
            ├─ 线性·SSM             ← Linear Transformer / RWKV / Mamba
            ├─ 生成范式              ← 自回归 vs MTP vs 扩散 LM vs 投机解码
            ├─ 前沿探索              ← BLT 字节级 / 记忆层 / TTT·Titans
            └─ 训练·对齐             ← 预训练 → SFT → RLHF/DPO + 缩放定律
```

**推荐浏览路线**：`2017 原版`（看懂 Encoder-Decoder 与 Attention 本体）→ `Decoder-Only·Dense`（对比现代 LLM 改了什么：RMSNorm/RoPE/GQA/SwiGLU）→ 按兴趣分流。

## 四、核心功能逐条解释

### 1. 真实前向传播（右栏 ▶）
输入「我 爱 自然语言处理」→ 字符分词 → embedding → 若干层 Attention+FFN → 输出下一个字符的概率分布。三套引擎对应三种视图：
- **2017 原版**：完整 Encoder-Decoder，Decoder 逐词生成（能看到 cross-attention）
- **Dense**：RMSNorm + RoPE + GQA + SwiGLU 的现代 Decoder
- **MoE**：Router Top-2 稀疏路由 + 专家负载统计（注意是示意实现：全专家算完再按门控合成）

### 2. 注意力热力图与三个视图
- 热力图：行=query 位置，列=key 位置，颜色=注意力权重。因果 mask 下呈下三角。
- **Model View**：全 N 层 × H 头的矩阵缩略总览，点一格定位到主视图。
- **Neuron View**：点热力图单元格，把 softmax(QKᵀ/√d) 分解到 Q·K 逐维点积——看"哪个维度贡献了这次注意"。

### 3. 让生成有语义（🎓 训练台）
- 默认权重随机初始化 → 输出乱码是**预期行为**（演示机制而非能力）。
- 「⬇ 加载权重」载入 TinyShakespeare 字符级模型（`tools/train.html` 浏览器内训练的产物，与演示架构逐算子一致），此后 Dense 生成即真实英文语义。
- 「⚡ 微调 40 步」对已加载权重跑真实 Adam 反向传播，loss 曲线实时绘制——图里被训练的变量就是可视化里前向的变量。

### 4. KV Cache 增量解码
开关打开后：Prefill 阶段一次算完整段 prompt 并缓存 K/V，之后每步只前向 1 个新 token。解码步的热力图 = 新 token 对全缓存的注意力。附「整段重算」耗时对照（微型模型上增量不占优属预期，收益随上下文长度放大）。

### 5. 采样控制
temperature / top-k / top-p 滑杆。Top-K 图表实时展示截断 + 重归一后的分布变形——直观看到 temperature 高→分布变平、top-k/p→砍掉长尾。

### 6. 单步调试控制台
底部播放条：▶ 播放 / ⏸ 暂停 / 单步前进 / 回退 / 跳转。日志里每一步（embedding、每层 QKV、softmax、FFN…）都可点击，跳转并弹出该步的解释抽屉（公式 + 张量形状 + 参数量 + 可运行代码）。

### 7. 代码导出
按当前超参数生成可运行的 tfjs 模型构建代码，一键复制——你在页面里调的超参和导出的代码完全一致。

## 五、术语速查

| 术语 | 白话 |
|------|------|
| Q/K/V | Query（我在找什么）/ Key（我是什么）/ Value（我的内容） |
| GQA | 多个 Q 头共享一组 K/V 头，省显存 |
| RoPE | 旋转位置编码：用旋转把位置信息乘进 Q/K |
| RMSNorm | 只做缩放的 LayerNorm（去掉均值中心化） |
| SwiGLU | FFN 激活函数：SiLU 门控版 |
| MoE | 专家混合：Router 给每个 token 挑 Top-K 个专家 |
| SSM/Mamba | 用递归状态替代注意力，长序列 O(n) |
| 投机解码 | 小模型先猜、大模型批量验证，加速生成 |
| KV Cache | 缓存历史 K/V，使自回归每步只需算新 token |

## 六、常见问题

**Q: 生成为什么是乱码？**
默认权重随机初始化，属预期。去训练台加载预训练权重即可获得有语义输出。

**Q: 微调后改超参为什么权重失效？**
预训练权重只适配 d128/h4/N3 配置，超参变了张量形状对不上，自动回退到随机初始化。

**Q: MoE 为什么没有变快？**
示意实现为教学目的全专家计算后按门控合成；真实推理只计算被选中的专家。

**Q: 双击 index.html 打不开权重加载？**
file:// 下 fetch 受限，请用 `python3 -m http.server 8642` 起本地服务。
